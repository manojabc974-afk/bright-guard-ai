# Bright Guard AI

## Project Description
Bright Guard AI is a phishing email detection system that identifies whether an email is safe or phishing using machine learning techniques.

## Features
- Detect phishing emails
- Classify emails as Safe or Phishing
- Display prediction results
- Machine learning based detection

## Technologies Used
- Python
- Scikit-learn
- Pandas

## How to Run
1. Install Python
2. Install required libraries
3. Run the project
